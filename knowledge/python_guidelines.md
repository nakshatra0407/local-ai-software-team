# Python Guidelines

## Code Style

Use clear and descriptive variable names.

Keep functions small and focused on one responsibility.

Use type hints when they improve readability.

Write readable and maintainable Python code.

## Error Handling

Handle expected exceptions explicitly.

Do not use bare except statements.

Raise meaningful exceptions when appropriate.

## Security

Never hardcode passwords, API keys, or secrets.

Validate external input before processing it.

Avoid executing untrusted code.

## Project Structure

Keep related functionality in separate modules when appropriate.

Prefer simple project structures for small applications.
