# Testing Guidelines

## Unit Testing

Write tests for individual functions.

Test both normal cases and edge cases.

Keep tests independent from each other.

## Assertions

Use clear assertions that describe expected behavior.

Test expected outputs for valid inputs.

Test error behavior for invalid inputs.

## Pytest

Use pytest for Python testing.

Name test files using the test_*.py pattern.

Name test functions using the test_ prefix.

## Test Quality

Tests should verify actual application behavior.

Do not modify tests simply to make failing code pass.
