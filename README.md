

A local multi-agent AI system that simulates a software engineering team.

## Goal

The system will use multiple AI agents to analyze software requirements,
design applications, generate code, test the code, debug failures,
and review the final project.

## Planned Agents

- Project Manager
- Architect
- Coding Agent
- Testing Agent
- Debugger
- Reviewer

## Technology Stack

- Python
- Qwen 2.5 1.5B
- Ollama
- FastAPI
- React + Vite
- Pytest
- SQLite
- FAISS
- Docker
- Git/GitHub
